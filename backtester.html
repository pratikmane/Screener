How to write a strategy

Write plain JavaScript. Two functions matter:

function prepare(d, ind, p) {
  // runs once. Return anything you
  // want to reuse (indicators etc.)
  return { ema: ind.ema(d.close, 20) };
}
function onBar(i, d, x, ctx) {
  // runs on every CLOSED candle i.
  // return null, or a trade:
  return { side:'buy', sl: 123.4, tp: 130 };
  // or use rr instead of tp:
  // { side:'sell', sl: 123.4, rr: 2 }
}

d has arrays open high low close volume time hour day. Only read index i or earlier, never i+1, or the result is fake. The one allowed peek is ctx.entry(side), the real entry price (next open plus spread).

ctx.skip('reason') counts why a signal was skipped. ctx.p holds the current parameter set.

Sweep: add const params = { n:[20,55], rr:[2,3] }; and read p.n, p.rr in your functions. The tool runs every combination (max 40) and shows a table.

Helpers (ind): sma, ema, rsi, atr(d,n,'sma'|'wilder'), adx, stdev, bbands, highest, lowest, swings(d,n), nearestSwing(...). See the templates for examples.

Trailing stop: add trail: { start: 2, dist: 1 } to the trade you return (price units). Once price has moved start in your favour, the stop follows dist behind the best price and never moves back. be: 1 moves the stop to break-even after a 1 move. Add noTp: true to drop the take-profit and let the trail run. The stop moves only after a candle closes.

Optional const config = { lots:0.01, maxBars:48, warmup:60 };

Only paste code you trust.

Trading costs

Position size

With a risk %, the lot size is worked out for every trade from the stop distance and the current balance. A strategy can also set this itself with config.riskPct and config.balance.

Risk limits

In-sample = the first part of the data. The rest (out-of-sample) is the honest check: a strategy should work on both.
